# Development Environment

## Dependencies & Core Components

### Z80 Disassembler (`src-rp/lib/z80dasm`)

The `z80dasm` library source files are integrated directly into this repository. All updates, modifications, and fixes to the disassembler should be made directly within this directory as standard repository files. No external tracking remotes are required.

The `z80dasm` exists as a utility command within `https://github.com/AESilky/z80util`.
